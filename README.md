# Cycling-Classic-Scifi-art-frame
![#f03c15](https://placehold.co/15x15/f03c15/f03c15.png) `Work in progress`<br>
I enjoy reading science fiction, and the artwork for the covers, especially some of the older ones, are great pieces of art on their own. Unfortunately they're stored in my library with only the spine visible.
Using a massive 13.3 color e-paper/e-ink display from waveshare (cutting edge at the time of this project creation, Aug 2026)!<br>

This will be all tucked away in a 15 inch photo frame with a battery. The e-ink cycles a random book cover from my collection of read science fiction books (I'll have to remember to update it) every 10 minutes. This makes it very low power consuming so it will only need to be charged every few months or so.<br>
